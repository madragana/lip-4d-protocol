# Contributing

Contributions, design discussion, and independent interoperability implementations are welcome.

1. Read the [experimental Internet-Draft](https://www.ietf.org/archive/id/draft-ovidi-lip-4d-00.html).
2. Propose changes through GitHub issues or pull requests, with concrete messages and reproducible tests.
3. Treat changes to wire messages, cryptography and policy decisions as security-sensitive.
4. Include positive, negative and cross-language test vectors for any protocol implementation changes.
5. Keep proprietary route.fast dependencies out of the vendor-neutral protocol core.

The IETF draft is work in progress; this repository is not an IETF-endorsed implementation or a claim of standards-track approval.
